# 最初に差し込む実写

`intro.mp4` を置き換えると、ゲームの最初の数秒がその映像になる。
いま入っているのは差し替え前提の仮の板で、`tools/` の ffmpeg で作った。

## 置き方

- ファイル名は `intro.mp4`（変えるなら `ColdOpen.ClipFile`）
- H.264 / mp4。Windows のエディタと実行ファイルはこれで確実に再生する
- 音は付けてよい。テープの AGC と飽和を通るので、こちらで音量は整う
- **4:3 が望ましい。** 4:3 以外は中に収めて余りを黒にする（切り落とさない）
- 長さは 6 秒以上あれば足りる。`ColdOpen.PlateSeconds`（既定 5 秒）まで映して落ちる

## 仕組み

映像は画面の上に重ねるのではなく、VHS のシェーダの中でシーンと
**差し替える**（`Vhs.shader` の `Sample()`）。帯域制限もドロップアウトも
タイムコードも同じように乗るので、1 本のテープが続いているように見える。
別経路で重ねると、切り替わった瞬間に「ここから作り物」だと分かってしまう。

## 権利について

他人の映像を入れるなら、このプロジェクトを公開しない前提を守ること
（`Assets/_Project/Audio/CREDITS.md` と同じ扱い）。

StreamingAssets の中身は Unity に取り込まれず、そのままビルドへ複製される。
`.mp4` を Assets に置いたときのような再エンコードは起きない。
