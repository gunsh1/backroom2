# 音の素材

## Step_Carpet.wav — じゅうたんの上を歩く足音

出所が確認できていない。利用者から
`artifacts/audio/じゅうたんの上を歩く (mp3cut.net).mp3` として渡されたもので、
mp3cut.net は切り出しの道具なので元の配布元が分からない。
**配布する段階までにライセンスを確認すること。** 差し替えが必要になった
場合は、Footsteps.Clips を空にすれば SoundBank の合成に戻る。

加工: 48kHz モノラルに変換 -> 45Hz 6 次ハイパス -> 立ち上がりで切り出し
-> 末尾 12ms フェード -> ピーク 0.90 に正規化。

元の録音は 16〜31Hz のうねりが全体の 93% を占めていた。録音時の
ハンドリングノイズで、足音そのものではないので落とした。可聴域の内訳は
63Hz 帯 74%、125Hz 帯 11%、1kHz 帯 4% (毛足の擦れ)。

## Voices/ — 呼び声

`male_*.wav` (2 本) / `female_*.wav` (7 本)。

出所は未確認。`artifacts/audio/` に置かれた録音 (`*_male.mp3`, `*_female.wav`) を
`tools/make-voices.py` で加工したもの。加工内容:

- 48kHz モノラルに統一 (male は 22.05kHz、female は 48kHz ステレオだった)
- 80Hz 6 次ハイパス
- 無音を切り、頭 8ms / 尻 40ms のフェード
- 群ごとに「声の出ている区間の rms」を 0.150 に統一
  (加工前は male 0.270-0.337 / female 0.113-0.372 と 10.4dB 開いていた)
- ピークを 0.95 に制限 (元素材に peak 1.414 の潰れがあった)

**配布前にライセンスの確認が要る。**
